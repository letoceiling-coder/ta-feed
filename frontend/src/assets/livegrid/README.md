# Иконки секции Live Grid

Иконки карточек категорий должны быть экспортированы из Figma (файл «Недвижимость-клиент», фрейм **node-id=4-13**) с прозрачным фоном.

**Список иконок (10 шт.):**

| Файл | Категория |
|------|-----------|
| `novostroyki.png` / `.svg` | Новостройки |
| `vtorichnaya.png` / `.svg` | Вторичная недвижимость |
| `arenda.png` / `.svg` | Аренда |
| `doma.png` / `.svg` | Дома |
| `uchastki.png` / `.svg` | Участки |
| `ipoteka.png` / `.svg` | Ипотека |
| `kvartiry.png` / `.svg` | Квартиры |
| `parkingi.png` / `.svg` | Паркинги |
| `kommercheskaya.png` / `.svg` | Коммерческая недвижимость |
| `podobrat.png` / `.svg` | Подобрать объект |

**Как экспортировать в Figma:**

1. Открыть: https://www.figma.com/design/CRzpnYXL4h8ud0LXsAclqG/Недвижимость-клиент?node-id=4-13  
2. В фрейме 4-13 найти каждую карточку категории и выделить слой с иконкой (3D/иллюстрация).  
3. ПКМ по слою → **Export** (или панель Export справа).  
4. Формат: **PNG** scale 2x с прозрачностью или **SVG**, если иконка векторная.  
5. Сохранить в эту папку (`frontend/src/assets/livegrid/`) с именами из таблицы выше.  

После экспорта обновить импорты в `frontend/src/data/categories.data.ts`, чтобы использовать новые файлы (при необходимости заменить расширение .png на .svg или наоборот).

Сейчас в коде используются существующие ассеты из `@/assets/` (cat-newbuild, cat-apartments и т.д.) и плейсхолдеры `arenda.svg` / `podobrat.svg` для двух категорий.
