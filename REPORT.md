## Структура базы данных

### Основные связи:
1. **Apartment** → **Building** → **Block** → **Builder**
2. **Apartment** → **Room** (комнатность)
3. **Apartment** → **Finishing** (отделка)
4. **Building** → **BuildingType** (технология строительства)
5. **Block** ↔ **Region** (many-to-many)
6. **Block** ↔ **Location** (many-to-many)
7. **Block** ↔ **Subway** (many-to-many с дополнительными полями)
8. **Building** ↔ **Mortgage** (many-to-many)

## Как использовать

### 1. Загрузка данных (на сервере):
```bash
php artisan feed:fetch msk
```

### 2. Фильтрация квартир:
```php
$filterService = new FilterService();
$apartments = $filterService->filterApartments([
    'price_min' => 5000000,
    'price_max' => 10000000,
    'area_min' => 30,
    'room_id' => 1,
])->get();
```

### 3. Получение данных с отношениями:
```php
$apartment = Apartment::with([
    'building.block.builder',
    'building.block.regions',
    'building.block.subways',
    'room',
    'finishing'
])->find(1);
```
