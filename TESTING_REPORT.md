## Что нужно сделать на сервере

### 1. Выполнить миграции (если еще не выполнены)

```bash
cd /var/www/ta-feed
php artisan migrate
```

### 2. Протестировать структуру данных

```bash
php artisan feed:test msk
```

**Ожидаемый результат:**
- ✓ about.json получен
- ✓ Все фиды найдены
- ✓ Структура данных соответствует документации

### 3. Загрузить данные

```bash
php artisan feed:fetch msk
```

**Ожидаемый результат:**
- Все данные загружены
- Файлы сохранены в `storage/app/feeds/msk/`
- Данные загружены в БД

### 4. Проверить целостность

```bash
php artisan feed:validate
```

**Ожидаемый результат:**
- Все справочники загружены
- Все основные данные загружены
- Все связи созданы
