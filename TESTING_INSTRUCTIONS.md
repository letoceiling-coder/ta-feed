# Инструкции по тестированию фида

## Важно

**Доступ к фидам ограничен по IP адресу.** Все запросы должны выполняться с сервера `89.169.39.244`, IP которого добавлен в белый список.

## Выполнение на сервере

### 1. Подключение к серверу

```bash
ssh root@89.169.39.244
```

### 2. Переход в директорию проекта

```bash
cd /var/www/ta-feed
```

### 3. Тестирование структуры данных

Выполните команду для проверки структуры фида:

```bash
php artisan feed:test msk
```

Эта команда:
- Проверяет доступность всех endpoints
- Валидирует структуру данных
- Сравнивает с документацией
- Показывает все доступные поля

### 4. Загрузка данных

После успешного тестирования загрузите данные:

```bash
php artisan feed:fetch msk
```

Эта команда:
- Загружает все данные из фида
- Сохраняет ответы API в `storage/app/feeds/msk/`
- Загружает данные в базу данных
- Создает все необходимые связи

### 5. Проверка целостности данных

После загрузки проверьте целостность данных:

```bash
php artisan feed:validate
```

Эта команда проверяет:
- Наличие данных во всех таблицах
- Целостность связей
- Соответствие документации
- Наличие обязательных полей

## Автоматическое тестирование

## Ожидаемые результаты

### Структура about.json

Должен содержать массив с объектами, каждый из которых имеет:
- `name` - название фида (blocks, builders, regions, и т.д.)
- `description` - описание
- `url` - ссылка на фид
- `exported_at` - дата последнего обновления

### Структура Blocks (ЖК)

Обязательные поля:
- `id` - ID ЖК
- `name` - Название ЖК
- `builder_id` - ID застройщика

Опциональные поля:
- `district` - массив ID регионов
- `locations` - массив ID локаций
- `subway` - массив объектов с полями:
  - `subway_id` - ID метро
  - `distance_time` - расстояние в минутах
  - `distance_type` - тип расстояния (1 - пешком, 2 - транспортом)
- `geometry` - геометка ЖК
- `renderer` - рендеры ЖК
- `progress` - ход строительства
- `plan` - ген. план

### Структура Buildings (Корпуса)

Обязательные поля:
- `id` - ID корпуса
- `block_id` - ID ЖК

Опциональные поля:
- `name` - название корпуса
- `queue` - очередь
- `address` - адрес
- `deadline` - срок сдачи
- `building_type` - ID технологии строительства
- `mortgages` - массив ID ипотечных программ
- `geometry` - геометка корпуса

### Структура Apartments (Квартиры)

Обязательные поля:
- `id` - ID квартиры
- `building_id` - ID корпуса

Опциональные поля:
- `area_given` - приведённая площадь
- `area_total` - общая площадь
- `area_rooms_total` - жилая площадь
- `finishing` - ID отделки
- `floor` - этаж
- `floors` - этажей в секции
- `number` - номер квартиры
- `plan` - планировка
- `price` - цена при 100% оплате
- `price_base` - базовая цена
- `room` - ID комнатности

## Проверка соответствия документации

После загрузки данных проверьте:

1. **Все справочники загружены:**
   - Застройщики
   - Регионы
   - Метро
   - Комнатность
   - Отделка
   - Технологии строительства

2. **Основные данные загружены:**
   - ЖК связаны с застройщиками
   - Корпуса связаны с ЖК
   - Квартиры связаны с корпусами

3. **Связи созданы:**
   - ЖК ↔ Регионы
   - ЖК ↔ Метро (с расстоянием)
   - Корпуса ↔ Ипотечные программы

4. **Данные соответствуют документации:**
   - Все поля из документации присутствуют
   - Типы данных соответствуют ожидаемым
   - Связи между объектами корректны

## Устранение проблем

### Ошибка 403 (Forbidden)

**Причина:** IP адрес не добавлен в белый список

**Решение:** 
- Обратитесь к менеджеру из отдела развития
- Предоставьте IP адрес сервера для добавления в белый список
- Доступы выдаются в пятницу после 15:00 по МСК

### Ошибка подключения

**Причина:** Проблемы с сетью или сервером

**Решение:**
- Проверьте доступность сервера: `ping dataout.trendagent.ru`
- Проверьте настройки firewall
- Проверьте логи: `storage/logs/laravel.log`

### Ошибки валидации данных

**Причина:** Структура данных не соответствует ожидаемой

**Решение:**
- Проверьте логи загрузки
- Сравните структуру с документацией
- Обратитесь к технической поддержке TrendAgent

## Логирование

Все ошибки логируются в:
- `storage/logs/laravel.log`

Для просмотра логов в реальном времени:
```bash
tail -f storage/logs/laravel.log
```

- `storage/app/feeds/{region}/builders.json`
- и т.д.

Эти файлы можно использовать для:
- Отладки

- Восстановления данных при необходимости
